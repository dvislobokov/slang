# Slang for VS Code

Syntax highlighting for `.sl` files. The grammar is `syntaxes/slang.tmLanguage.json`.

To try it locally: copy this folder to `~/.vscode/extensions/slang-lang` and
reload VS Code. Language-server features (completion, go-to-definition,
diagnostics) will come from `slang lsp`; see `docs/TOOLING.md`.
