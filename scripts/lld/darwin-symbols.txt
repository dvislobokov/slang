# C symbols of macOS libSystem (libsystem_c, _kernel, _m, _pthread, _malloc,
# libdyld, ...) that scripts/bundle-targets.sh lists in the bundled
# libSystem.tbd besides what the runtime archive itself imports: the libcalls
# LLVM emits for generated code and the common C11/POSIX API for FFI
# declarations. One C name per line (the tbd gets the leading underscore;
# a line "=name" is a raw Mach-O symbol name).
# Every name must exist in libSystem of macOS 12+ on arm64 and x86_64; the
# macOS CI job checks this list against the SDK's .tbd files
# (scripts/bundle-targets.sh --check-darwin-tbd).
